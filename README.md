this is a solution project for [roadmapsh](https://roadmap.sh/projects/github-user-activity)

## Features

- Look up the activity of any GitHub user by username
- Filter results by event type (for example, `PushEvent`)
- View all events in your browser as a simple JSON response
- No filter? You get every event for that user

## Installation

```bash
git clone https://github.com/10pie/gitHub-events-webApp.git
cd gitHub-events-webApp
```

## Usage

Start the application, passing your arguments through Maven:

```bash
mvn spring-boot:run "-Dspring-boot.run.arguments=--username=your_username --filterType=type_wanted"
```

Once the server starts, open this URL in your browser:

```
http://localhost:8081/api/github/get
```

## Arguments

| Argument | Required | Description |
|----------|:--------:|-------------|
| `--username` | Yes | The GitHub username whose activity you want to see |
| `--filterType` | No | Only show events of this type. Omit to see all events |

## Examples

**All events for a user:**

```bash
mvn spring-boot:run "-Dspring-boot.run.arguments=--username=octocat"
```

**Only push events:**

```bash
mvn spring-boot:run "-Dspring-boot.run.arguments=--username=octocat --filterType=PushEvent"
```

Then visit `http://localhost:8081/api/github/get`.

## Troubleshooting

| Problem | Solution |
|---------|----------|
| Port 8081 already in use | Stop the other process, or change `server.port` in `application.properties` |
| Empty response | Check the username spelling and that the user has recent public activity |
| Arguments ignored | Ensure the property is spelled `spring-boot.run.arguments` and the whole value is wrapped in quotes |
